## 项目简介

本项目由中国药科大学中药学院**组分结构创新中药实验室**研发，整合国家发布的 **106 种食药物质目录**资源，通过信息化手段为功能食品的组分结构解析、智能组方设计、潜在应用挖掘及感官营养评估提供一站式数据支撑与算法工具。

**核心定位：**
- 面向功能食品开发场景，严格遵循国家食药物质管理规范
- 服务于高校科研、课题组汇报、产学研合作展示等学术用途
- 为后续接入后端数据库、AI 组方模型预留标准化接口

## 平台功能模块

### 1. 食药物质基本信息
- 收录 106 种国家食药物质目录品种
- 支持分页浏览、关键词检索与详情查看
- 详情页采用 TCMSP 风格：图片 + 成分靶点概览 + ADME 参数 + 关联文献

### 2. 功能食品组方设计
- 功能导向的智能组方引擎（血糖调节、血压调节、睡眠改善等）
- 虚拟筛选子模块（对标 TCMSP ADME 参数）
- **九维加权评分模型**：功能靶点覆盖率 / 网络拓扑 / ADME / 协同性 / 安全性 / 口感 / 气味 / 颜色 / 营养

### 3. 潜在应用数据挖掘
- 基于古今中外文献与实验数据深度挖掘
- 模糊检索、错字纠正、多语言翻译
- 按来源（古代文献 / 现代药理 / 临床研究 / 网络预测）与成分类型筛选

### 4. 感官预测及营养评估
- 口感、气味、颜色三维感官预测
- 营养价值加权评估（基于 106 种物质营养物质检测数据）

## 数据来源

| 数据类型 | 来源 |
|---------|------|
| 食药物质目录 | 国家卫健委《既是食品又是中药材的物质目录》 |
| 药典文本 | 《中华人民共和国药典》（2020 版） |
| 文献数据 | mockData 部分为模拟数据，后续逐条替换为真实文献 |
| 实验数据 | 课题组自主实验（电子舌、电子鼻、颜色测定、营养成分） |
